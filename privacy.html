隱私權政策

教練小幫手（Coach Mate）· 最後更新：2026 年 8 月 7 日

簡單講：這個 App 不收集你的任何資料。沒有伺服器、沒有帳號、沒有分析追蹤。你輸入的學生、課表與收費，全部只存在你自己的裝置裡。

這份政策同時適用於 iOS App「教練小幫手」與網頁版（huang940818-art.github.io/coach-mate-web）。

一、我們收集哪些資料

沒有。開發者看不到、也拿不到你在 App 裡輸入的任何內容。具體來說：

  • 沒有註冊、沒有登入、沒有帳號
  • 沒有任何伺服器接收你的資料
  • 沒有分析工具、沒有廣告、沒有第三方 SDK
  • 沒有跨 App 或跨網站追蹤

iOS App 完全不具備連上網路的功能——這不只是「我們不傳」，而是程式裡根本沒有任何網路連線的程式碼。

二、你的資料存在哪裡

版本存放位置
iOS App 你 iPhone 上這個 App 自己的資料庫。與桌面小工具共用，兩者都在你的裝置內。
網頁版 你瀏覽器的本機儲存空間（localStorage）。換瀏覽器或換裝置就看不到，因為它從未離開原本那一台。

資料不會自動備份到雲端，也沒有同步功能。這代表隱私性很高，但也代表裝置遺失或損壞時資料會消失，請定期使用 App 內的「匯出備份」功能自行保存。

三、權限的用途

相機

只有在你主動使用「拍照自動填入」或替 InBody 紀錄拍照時才會啟用。文字辨識（OCR）完全在你的裝置上進行，使用 Apple 內建的 Vision 框架，照片與辨識結果都不會離開裝置。

相片

只有在你主動選取照片時才會讀取。選中的照片會存進 App 的本機資料庫，不會上傳到任何地方。

通知

用於課前提醒與月底回顧提醒。這些是本機通知，由你的裝置自己產生與排程，沒有遠端推播，開發者無從得知你有哪些課。

以上權限你都可以拒絕或隨時在 iOS「設定」中關閉，App 的其他功能不受影響。

四、資料在什麼情況下會離開你的裝置

只有兩種情形，而且都必須由你主動操作：

1. 你自己匯出備份

當你使用「匯出資料」時，會產生一個 JSON 檔，存放到你指定的位置（檔案 App、雲端硬碟、傳給自己等）。這個檔案完全由你控制，開發者不會收到副本。

2. 你使用「回報問題」

這個功能會開啟你的郵件程式並預先填好內容，你必須自己按下寄出才會送出。內容包含：

  • 你輸入的問題描述
  • App 版本、裝置機型、系統版本
  • 資料筆數（例如「學生 12、課程 200」）
  • 你選填的聯絡方式

不包含學生姓名、電話、備註、照片或任何課程與收費的內容。

五、第三方

App 沒有使用任何第三方程式庫或服務。

網頁版託管在 GitHub Pages 上。跟任何網站一樣，你的瀏覽器向 GitHub 請求網頁檔案時，GitHub 會依其自身政策處理連線記錄（例如 IP 位址）。這是網頁託管本身的性質，與 App 內容無關，我們也接觸不到這些記錄。詳見 GitHub 隱私權聲明。

六、兒童

本 App 是給健身與運動教練管理自己業務用的工具，並非針對兒童設計，也不會刻意向兒童收集資料（實際上不向任何人收集資料）。

七、如何刪除你的資料

  • App：到「設定 → 清除所有資料」，或直接把 App 從裝置上刪除。
  • 網頁版：到「設定 → 清除所有資料」，或清除瀏覽器對本網站的資料。

因為資料只存在你的裝置上，刪除之後就真的沒有了，我們這邊沒有任何副本可以復原。

八、政策變更

若之後新增了會改變資料處理方式的功能（例如雲端同步），我們會更新這份政策並修改上方的日期。重大變更會在 App 內主動告知。

Privacy Policy

Coach Mate (教練小幫手) · Last updated: 7 August 2026

In short: this app collects nothing. There are no servers, no accounts, and no analytics. Everything you enter stays on your own device.

1. Data we collect

None. There is no sign-up, no account, no server that receives your data, no analytics, no advertising, no third-party SDKs, and no tracking of any kind. The iOS app contains no networking code at all — it is not that we choose not to transmit data, it is that the capability does not exist in the app.

2. Where your data lives

iOS app: in the app's own local database on your iPhone, shared only with its home-screen widget. Web version: in your browser's localStorage. Nothing is synced or backed up to any cloud service, which also means data is lost if the device is lost — please use the built-in export feature to keep your own backups.

3. Permissions

Camera — used only when you choose to scan text or photograph an InBody record. Text recognition runs entirely on-device using Apple's Vision framework. Photos — read only when you pick an image; it is stored in the local database and never uploaded. Notifications — local notifications only, scheduled by your own device for class and monthly reminders. There is no remote push. All permissions are optional.

4. When data leaves your device

Only when you deliberately make it happen: (a) exporting a backup file to a location you choose, or (b) using "Report a problem", which opens a pre-filled email draft that you must send. That email contains your description, the app version, device model, OS version, record counts, and any contact details you choose to add — never student names, phone numbers, notes, photos, lesson or payment details.

5. Third parties

The app uses no third-party libraries or services. The web version is hosted on GitHub Pages; as with any website, GitHub processes connection information such as IP addresses under its own policy. We have no access to those logs.

6. Children

This is a business tool for fitness and sports coaches. It is not directed at children and collects no data from anyone.

7. Deleting your data

Use "Settings → Clear all data", or delete the app. Because the data exists only on your device, deletion is permanent and we hold no copy to restore.

8. Changes

If a future feature changes how data is handled (for example cloud sync), this policy will be updated and the date above revised. Significant changes will also be announced inside the app.
