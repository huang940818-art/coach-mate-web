常見問題

我的資料存在哪裡？會不會不見？

資料只存在你自己的裝置上，沒有雲端、沒有同步，所以別人看不到你的學生——但也代表裝置遺失、損壞或重灌時資料會消失。

請養成定期備份的習慣：設定 → 匯出資料，會產生一個 JSON 檔，存到「檔案」App 或雲端硬碟。建議時機：輸入完一批學生之後、每個月底、換手機之前。

換手機怎麼把資料搬過去？
  1. 舊手機：設定 → 匯出資料，得到一個 JSON 檔
  2. 用 AirDrop、LINE 或 Email 把檔案傳到新手機
  3. 新手機：設定 → 匯入資料 → 選那個檔 → 選「取代全部」

App 與網頁版的備份檔格式相同，可以互相搬。

網頁版加到主畫面之後，學生都不見了？

資料沒有不見，還在原本的瀏覽器裡。這是 iPhone 的規則：加到主畫面的圖示與 Safari 是分開存資料的，兩邊不互通。

解法：回到瀏覽器打開同一個網址 → 設定 →「加到主畫面 → 怎麼加？」，它會把資料一起帶過去。資料量太大帶不動的話，改用「複製備份文字」，再到桌面圖示裡「貼上備份文字」。

最省事的做法是一開始就先加到主畫面，之後都從桌面圖示開來用。

「檢測」是什麼？跟正課差在哪？

檢測是對還沒買課的人做的第一次試教。它會佔用課表的時段，但不扣堂數、不算課程收入、也不進抽成，因為對方還沒付錢。

時段過了 App 會問你「成交了嗎」。成交就直接把他轉成正式學生並接續約流程；沒成交就留在待追蹤名單。成交率在「回顧」頁看得到，還能依名單來源拆開看。

剩餘堂數不對，可以自己改嗎？

可以。到學生詳情頁，點「剩餘 N 堂」那個數字就能直接調整，有快速加減按鈕，也可以填調整原因（會記進備註，之後對帳查得到）。

這個功能只改剩餘堂數，不會動到已購堂數，所以銷售統計不受影響。要記錄新買的堂數請用「續約」。

底薪怎麼設定？我們公司的算法不太一樣

設定裡的底薪支援三種常見算法：

  • 底薪＋抽成：底薪固定給，抽成另外加
  • 達標後取消底薪：堂數沒到門檻時有底薪保護，到了門檻就只領抽成
  • 取高者：底薪與抽成比大小，領高的那個，不相加

薪資頁會用一句話說明這個月的底薪為什麼是這個數字。

同一堂課有兩個學生一起上怎麼記？

排課時選好主要學生，再選「共同上課」的第二位。兩位各扣一堂，課程收入與薪資也各算一份。

名單上同一個人出現兩次

到設定 → 資料管理，如果偵測到同名同電話的重複，那裡會出現「清掉重複的學生」。它會列出有幾組、以及會連帶刪掉幾堂課與幾筆收費，確認後才動手。每個人只會留下資料最完整的那一筆。

建議先匯出一份備份再操作。

App 想改成深色（或淺色）

設定最上面的「深色模式」可以選跟隨系統／淺色／深色。選了淺色或深色就會固定，不管手機本身的設定是什麼。

Contact

Where is my data?

Entirely on your own device — there is no cloud and no sync. That keeps your students private, but it also means data is lost if the device is lost. Use Settings → Export data regularly to keep your own backup file.

Moving to a new phone

Export a backup on the old device, transfer the file (AirDrop, email, cloud drive), then use Settings → Import data → Replace all on the new one. The iOS app and the web version share the same backup format.
